# 大师滤镜宫格（MasterGrid）

给 OPPO 相机「大师模式」加一个滤镜宫格：导入的滤镜一多，左右滑着找很费劲。装上之后，大师模式里会出现一个悬浮按钮，点开就能看到自己导入的所有滤镜（3 列宫格），点哪个就自动切到哪个。

它是一个无障碍服务：读取相机界面上的滤镜名称，再模拟手势完成切换。不改相机、不需要 root，也不需要悬浮窗权限。

## 功能

- **宫格选滤镜**：列出「标准」左边你自己导入的滤镜，名字按「基底 - 名称」拆开显示，当前滤镜高亮。
- **快速切换**：距离远时用滤镜名下方的圆点指示条快速拨动（约 0.12 秒一格），接近目标后再逐格滑动收尾。
- **一键扫描**：自动把大师模式的滤镜列表滑一遍，记下完整顺序，扫完切回原来的滤镜。
- **排序与隐藏**：在设置页拖动排序，或点「按风格分组」把同一基底风格的滤镜排在一起；取消勾选就能在宫格里隐藏。
- **选中后自动退回拍摄界面**（可选）。
- 竖屏、横屏都能用；悬浮按钮可以拖动，横竖屏各记一个位置。

## 适配情况

目前只在这台设备上测试过：

| 项目 | 版本 |
|---|---|
| 机型 | OPPO Find X8 Ultra（PKJ110） |
| 系统 | ColorOS 16.1 |
| 相机 | 6.070.228 |

程序是通过相机界面的控件 id 来识别界面的（见 `CameraDriver.kt` 末尾），换了机型或者相机版本以后可能要改。最低要求 Android 11（API 30）。

## 安装

### 直接下载（推荐）

1. 在手机浏览器里打开 [最新 Release](https://github.com/xuyunfan9991/MasterGrid/releases/latest)，下载 `MasterGrid-vX.X.apk`。
2. 点开下载好的 APK 安装。如果提示「禁止安装未知来源应用」，按提示允许浏览器（或文件管理）安装应用即可。
3. 打开「大师滤镜宫格」，点「打开无障碍设置」，在「已下载的应用」里打开「大师滤镜宫格」。

> 如果无障碍开关是灰的，点了提示「受限设置」：先到 **设置 → 应用 → 大师滤镜宫格**，点右上角 ⋮ →「**允许受限设置**」，再回去打开无障碍开关。这是 Android 13 以后对「从浏览器下载安装的应用」的限制。

### 自己编译

需要 JDK 17 和 Android SDK（compileSdk 36）。

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`./gradlew assembleRelease` 编译发布版时，如果项目根目录有 `keystore.properties`（包含 `storeFile`、`storePassword`、`keyAlias`、`keyPassword` 四项），就用其中的密钥签名；没有这个文件时自动改用调试密钥。这个文件和密钥文件都不会提交到 git。

ColorOS 用 `adb install` 时，手机上会弹一个确认框，要点「继续安装」，否则会报错 `-99`。装好后同样要按上面第 3 步开启无障碍服务。

## 使用

1. 打开相机，切到**大师模式**，屏幕边上会出现 ▦ 悬浮按钮。
2. 第一次使用先点 ▦ →「**扫描滤镜**」。扫描时它会自动滑动，请别碰屏幕。
3. 之后点 ▦ 打开宫格，点滤镜名就会自动切过去。
4. 新导入或删掉滤镜以后，再扫描一次。
5. 在宫格里点「设置」进入设置页，可以排序、隐藏滤镜，也可以设置选中后自动退回。

## 实现要点

- **识别界面**：通过相机控件的 resource-id 判断当前是大师模式拍摄界面还是滤镜界面，并读取 `effect_style_filter_hint` 上的滤镜名。
- **快速拨动**：按住圆点指示条（`EffectStylePageIndicator`），它会展开（实测长边 368px → 512px）；手指移到展开后的范围外并保持不动，相机就会自动一格一格往前翻。要按在反方向尽头的圆点上，按在中间可能一格都不翻。
- **方向自动校准**：不同屏幕方向下的滑动方向和拨动方向会在运行时自动校准，结果保存下来。

### ColorOS 的坑

- **反诈拦截**：无障碍应用只要加了全屏覆盖层，大约 2 秒后就会被 ColorOS 的反诈模块（`FraudBehaviorDetectManager`）直接关掉服务。所以宫格面板只做成卡片大小，不能用全屏窗口。
- **`uiautomator dump` 会暂停其他无障碍服务**，悬浮按钮会闪，正在进行的自动操作也会中断。调试请用 `adb logcat -s MasterGrid:*`。
- 宫格面板刚关闭的一瞬间（约 80ms 内），相机会忽略新的触摸，所以要先等 100ms 再开始操作。
- 带 `willContinue` 的连续手势，系统大约 20ms 就会回调，不管手势设置的时长是多少，按住的时间要自己延时。

## 项目结构

```
app/src/main/java/com/xyf/mastergrid/
├── MasterGridService.kt   无障碍服务入口：监听相机界面，调度扫描和切换
├── CameraDriver.kt        识别相机界面、读取滤镜名、模拟滑动和快速拨动
├── Overlay.kt             悬浮按钮、宫格面板、提示气泡
├── FilterStore.kt         本地存储：滤镜顺序、排序/隐藏、方向校准、按钮位置
└── MainActivity.kt        设置页
```

## 隐私

只读取相机界面上的滤镜名称。所有数据都存在手机本地，不联网，不收集也不上传任何信息（App 没有申请网络权限）。
